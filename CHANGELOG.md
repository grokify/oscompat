## [v0.3.0] - 2026-04-27

### Changed

## [v0.1.0] - 2025-01-17

### Highlights

- Initial release with cross-platform utilities for Go

### Added

- `id` package: Cross-platform unique identifier generation using `crypto/rand`
- `process` package: Cross-platform process management (detach, signal)
- `paths` package: XDG-compliant config/data/cache directory resolution
- `fs` package: Path validation, normalization, permissions, birthtime
- `tsync` package: Tolerant timestamp comparison for file sync
- `localnet` package: Cross-platform local IPC (Unix sockets / TCP)
