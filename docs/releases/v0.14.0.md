# Release Notes v0.14.0

Released: 2026-11-23

## Highlights

Skip a test that needs a POSIX platform with one call that says why, so
callers need no `runtime.GOOS` check.

## New Features

### testutil.RequirePOSIX

```go
func TestDeployRunsTheHooks(t *testing.T) {
    testutil.RequirePOSIX(t, "the hooks are shell scripts run as programs")
    // ...
}
```

The test is skipped on Windows, with "needs a POSIX platform: " and the
reason, because Windows runs no `#!` script as a program, keeps no execute
bits, and does not treat a `/`-rooted path as absolute. `testutil.POSIX()`
reports the same, for a test that only adjusts an assertion.

## Upgrading

Nothing changes for existing callers.
